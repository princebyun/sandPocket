# [SandPocket] 메인 화면 재디자인 & 플랫폼 아이덴티티 정상화 작업계획서

**문서 버전:** 2.1.0 (디자인 요청 검증 및 메인 구조 개편안)  
**작성일:** 2026-10-06  
**레퍼런스 사이트:** [로보토리 (Robotori) 인트로](https://robotori.co.kr/v2/index/html/main/intro.html)  
**대상 시스템:** SandPocket (WASM 기반 안전한 코드 샌드박스 & 에듀테크 플랫폼)

## 1. 사용자의 기존 디자인 요청 내역 분석 및 점검

### 1.1 과거 요청 사항 히스토리
1. **1차 요청:**
   - "기존 디자인이 너무 AI가 만든 것 같아 어색함. 전체적으로 디자인을 환골탈태하고 신뢰감 높은 프로덕트로 개편 희망."
2. **2차 요청 (레퍼런스 지정):**
   - 레퍼런스 URL: `https://robotori.co.kr/v2/index/html/main/intro.html`
   - 핵심 지침: "해당 링크 페이지를 참고해서 최대한 비슷하게 디자인 작업계획까지 추가해서 작업계획서 작성."
3. **현재 문제점 피드백:**
   - **현상:** 메인 화면 히어로 영역에 `뱀 게임(Python)`과 `피보나치 수열(Java)`이 각각 50:50으로 전면에 노출됨.
   - **지적 사항:** 이 2가지는 플랫폼 전체의 정체성이 아니라 **"게시판에 등록된 개별 예시 게시글"**에 불과함. 이를 메인 화면의 메인 테마로 대대적으로 내세우는 것은 잘못된 구조임.

### 1.2 기존 구현의 오해 및 원인 분석
* **원인:** 로보토리 인트로의 좌우 50:50 구조(`ROBOTORI BRAND` vs `ROBOTORI EDU`)를 옮겨오면서, 마침 DB 시드 데이터로 존재하던 두 샘플 프로젝트(뱀 게임, Java 피보나치)의 제목과 링크를 히어로 버튼과 카피에 직접 매핑해버리는 오류 발생.
* **결과:** 사용자가 접속했을 때 플랫폼이 아닌 '뱀 게임과 피보나치 계산기 전용 사이트'처럼 인식되는 심각한 UX 왜곡 발생.

### 2.1 메인 히어로 섹션 (Hero Split)
* **Left Panel (로보토리 시그니처 로열 블루 `#2B65FE`):**
  - **영역 정의:** `SANDPOCKET STUDIO` (직접 코딩하고 실행해보는 창작자 공간)
  - **헤드라인:**  
    `AI 바이브코딩의 시작,`  
    `브라우저에서 즉시 구동되는`  
    `초경량 WASM 샌드박스!`
  - **설명:** 서버 설치나 클라우드 비용 없이 브라우저 내부 WebAssembly 가상 환경에서 Python과 Java 코드를 안전하게 테스트하고 빌드합니다.
  - **CTA 버튼:** `새 프로젝트 제작하기 ➔` (이동 경로: `/upload`)
* **Right Panel (로보토리 딥 블랙 `#111111`):**
  - **영역 정의:** `CREATOR SHOWCASE` (다른 창작자들의 프로젝트를 탐색하는 공간)
  - **헤드라인:**  
    `상상을 현실로,`  
    `크리에이터들의 창작물을`  
    `함께 즐기는 오픈 아카이브`
  - **설명:** 커뮤니티 개발자들이 AI와 함께 창작한 인터랙티브 Canvas 게임, 알고리즘, 웹 유틸리티를 자유롭게 실행하고 소스코드를 분석해 보세요.
  - **CTA 버튼:** `창작 갤러리 둘러보기 ➔` (이동 경로: `#project-list` 부드러운 스크롤 이동)

### 2.2 플랫폼 신뢰도 & 기술 강점 하이라이트 (Feature Ribbon)
* 메인 히어로 바로 하단에 로보토리의 정돈된 화이트 라운드 캡슐 스타일을 계승한 3열 특장점 띠 배너 추가:
  1. **클라이언트 샌드박스 격리:** 브라우저 Web Worker 격리로 메인 스레드 정지 및 무한루프 완벽 차단.
  2. **100% 제로 설치 구동:** Pyodide(Python 3.12) & CheerpJ(JVM) 내장으로 어떤 환경에서든 즉각 실행.
  3. **실시간 정적 보안 검사:** 악성 시스템 호출, 위험 라이브러리 접근을 사전 차단하는 다층 방어막.

### 2.3 커뮤니티 프로젝트 게시판/갤러리 (Bento Grid)
* **뱀 게임**과 **Java 피보나치 데모**는 바로 이 하단 게시판의 **일반 등록 작품(샘플 카드)**으로 격하 배치.
* 게시판 상단 검색 및 카테고리 필터(`전체`, `게임`, `웹/알고리즘`)와 유기적으로 연동.
* 카드 호버 시 로보토리 특유의 서클 아이콘 리빌 애니메이션(`.circle-icon`) 유지.

## 3. 세부 구현 작업 계획 (Implementation Steps)

### Step 1: 메인 페이지 컴포넌트 구조 개편 ([app/page.js](file:///d:/princebyun/sandPocket/app/page.js))
1. 히어로 카피 및 액션 버튼을 특정 데모 프로젝트(`demo-ai-snake-game`, `demo-java-hello`) 하드코딩에서 플랫폼 고유의 브랜딩 메시지로 전면 수정.
2. Left 패널 CTA를 `/upload` (새 프로젝트 제작), Right 패널 CTA를 `#project-list` (갤러리 둘러보기)로 연결.
3. 히어로 하단에 3열 특장점 배너(`Platform Highlights`) 섹션 추가.
4. 게시판 섹션 제목을 `커뮤니티 창작 갤러리`로 명확히 정의하고, 뱀 게임과 Java 데모가 일반 프로젝트 카드로서 그리드 안에서 조회되도록 정돈.

### Step 2: 스타일시트 고도화 ([app/globals.css](file:///d:/princebyun/sandPocket/app/globals.css))
1. 히어로 패널 내 텍스트 계층 구조 및 서브 캡션 가독성 최적화.
2. 새롭게 추가되는 특장점 배너 리본(`.feature-ribbon`)용 로보토리 감성 디자인 토큰(라운드 24px, 미세 보더, 부드러운 호버 모션) 정의.
3. 모바일 반응형(768px 이하)에서 스플릿 패널이 자연스럽게 세로 스택으로 전환되고 터치 친화적 패딩을 유지하도록 보강.

### Step 3: 프로젝트 샘플 메타데이터 및 갤러리 정돈 ([lib/db.js](file:///d:/princebyun/sandPocket/lib/db.js))
1. '뱀 게임'과 'Java 피보나치 계산기'의 게시물 타이틀/설명 문구를 "게시판 예시 작품" 맥락에 맞게 가다듬기 (예: `[예시] 캔버스 뱀 게임 (Python 3.12)`, `[예시] 콘솔 알고리즘 계산기 (Java 8)`).
2. 사용자가 언제든 새로운 작품을 추가하고 둘러볼 수 있는 열린 커뮤니티 구조 보장.

### Step 4: 동작 및 렌더링 검증
1. 메인 접속 시 뱀 게임/피보나치가 메인 히어로를 잠식하지 않고 플랫폼 브랜딩이 시원하게 전달되는지 확인.
2. 좌/우 캡슐 버튼 클릭 시 각각 프로젝트 등록 페이지(`/upload`) 및 하단 갤러리(`#project-list`)로 정확히 이동하는지 검증.
3. 반응형 뷰포트(데스크톱, 태블릿, 모바일)에서 레이아웃 깨짐 없는지 확인.
